# Справочник параметров (русский)

Скрипт `./scripts/setup.sh` интерактивно создаёт локальный `.env` с правами `0600`. Он запрашивает Device ID, IP розетки, **техническое** имя Zabbix-хоста, адрес сервера и полный путь к существующему TinyTuya `devices.json`.

## Параметры `.env`

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `TUYA_DEVICE_ID` | да | — | Идентификатор розетки, должен совпадать с `devices.json` |
| `TUYA_DEVICE_IP` | да | — | Локальный IP розетки |
| `TUYA_DEVICES_FILE` | да | `/config/devices.json` внутри контейнера | Файл с Local Key, подключённый Compose в `/config/devices.json` |
| `TUYA_VERSION` | нет | `3.5` | Версия локального протокола Tuya |
| `ZABBIX_HOST` | да | — | Точное техническое имя хоста в Zabbix |
| `ZABBIX_SERVER` | нет | `127.0.0.1` | Адрес Zabbix Server, доступный из контейнера |
| `ZABBIX_PORT` | нет | `10051` | Порт приёма Zabbix trapper |
| `POLL_INTERVAL_SECONDS` | нет | `60` | Интервал опроса, минимум 15 секунд |
| `DPS_RELAY` | нет | `1` | Состояние реле |
| `DPS_CURRENT` | нет | `18` | Ток |
| `DPS_POWER` | нет | `19` | Мощность |
| `DPS_VOLTAGE` | нет | `20` | Напряжение |
| `DPS_COUNTDOWN` | нет | `9` | Необязательный таймер |
| `DPS_RESTORE_MODE` | нет | `38` | Необязательный режим восстановления |
| `CURRENT_DIVISOR` | нет | `1000` | Коэффициент пересчёта тока в амперы |
| `POWER_DIVISOR` | нет | `10` | Коэффициент пересчёта мощности в ватты |
| `VOLTAGE_DIVISOR` | нет | `10` | Коэффициент пересчёта напряжения в вольты |
| `DOCKERHUB_USERNAME` | для образа Docker Hub | — | Имя аккаунта / организации в Docker Hub |
| `IMAGE_TAG` | нет | `latest` | Тег опубликованного образа |

Для розеток других производителей / ревизий сначала проверь реальный набор DPS. Отсутствующие необязательные параметры не подменяются нулями.

### Несколько розеток

Один контейнер обслуживает одну розетку. Для следующих устройств используй тот же образ, но отдельные настройки, имена контейнеров и хостов Zabbix. Все контейнеры могут читать один `devices.json` в режиме `read-only`.

### Разрешённые отправители

В двух элементах типа Zabbix trapper `tuya.poll.ok` и `tuya.status.raw` необходимо настроить **Allowed hosts**. При `network_mode: host` и Zabbix Server в bridge-сети источником может быть шлюз Docker-сети (а не `127.0.0.1`). Посмотри Gateway через `docker inspect zabbix-server`, проверь источник подключения и внеси его в список. После изменения при необходимости обнови кеш конфигурации Zabbix.
